# EV_APIS

This project is a Node.js-based REST API to manage Electric Vehicles (EVs). It provides basic CRUD (Create, Read, Update, Delete) operations for managing a dataset of EVs..


1.Clone the repository:
git clone https://github.com/abishekg45/EV_APIS.git

2.Install dependencies:
    # npm install

3.Start the Server
    # npm start

Port Number : 3000
